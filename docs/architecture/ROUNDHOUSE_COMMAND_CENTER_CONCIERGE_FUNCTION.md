# Roundhouse Command Center — Concierge Function

## Purpose

The Concierge is a **Command Center function, not a separate screen**.

It is Roundhouse's work assistant. It remains available while the person is actively working in the Command Center and appropriate Roundhouse work destinations, helping turn questions, observations, photographs, research, and spoken instructions into useful Roundhouse actions and records.

The Concierge is not a general-purpose chatbot. Its role is practical Roundhouse work and day planning. Politics, religion, dating advice, and unrelated personal counseling are outside its role.

## CAPTURE Interaction

The existing **CAPTURE** button is the Concierge entry point. The Concierge does not receive another permanent Command Center button.

**Tap CAPTURE = Capture.**  
A normal tap opens the capture choices, including **Photo** and **Notation**.

**Press and hold CAPTURE = Talk to Concierge.**  
The hold must be deliberate enough to avoid accidental Concierge activation during normal capture. Activation should provide clear haptic and visual feedback.

When Concierge is active, CAPTURE becomes visibly animated, such as an active ring or pulse around the button. The animation communicates that a Concierge working session is currently active.

Pressing and holding the active Concierge control again ends the Concierge session.

## Working Session

The Concierge is not a screen that traps the person inside a chat interface. She remains active while the person continues working.

Example:

1. Person holds CAPTURE and asks what replacement part is needed.
2. Concierge says, **“Send me a picture of the model plate.”**
3. CAPTURE remains usable normally.
4. Person taps CAPTURE and chooses **Photo**.
5. The photograph becomes part of the active Concierge context.
6. Concierge can identify or research the relevant information.
7. Person can direct the useful result into Roundhouse, such as **“Add that part to my shopping list”** or **“Document that model number on this Property.”**

The useful result should become Roundhouse information rather than remaining buried only inside an AI conversation.

**Ask → Research → Decide → Save to Roundhouse → Retrieve when needed.**

## Command Center Continuity

While Concierge is active, the person can continue using the Command Center and its working tools.

The right-side Command Center tabs remain available. Concierge can remain active while the person opens and works within **Daily Grind, Tasks / Lists, Receipts, Properties**, and other Command Center working overlays.

If the person enters a deeper work destination from the lower Command Center controls, such as **Resolutions, People, Estimates / Invoices, or Calendar**, an already-active Concierge session may follow into that work destination. The active Concierge control remains available in a small, unobtrusive form so the person can continue asking for help in the current work context.

If the person press-holds the active Concierge control while inside one of those destinations, the Concierge session ends and the Concierge control is removed from that destination. The normal Back control returns the person to the Command Center.

## Hard Boundaries

The Concierge does **not** follow the person into:

- **Mail / Messages**
- **Reward Center**

Those are separate experiences where an active assistant would feel intrusive. Entering either ends or removes the active Concierge presence.

## Daily Grind Appearance

Daily Grind is where the Concierge may appear proactively.

The first time the person signs in for the day, Daily Grind automatically opens over most of the Command Center. Concierge can provide a practical morning briefing and help the person make the day's plan.

The briefing may include:

- today's planned work and appointments;
- useful heads-up information about tomorrow;
- shopping-list needs;
- incomplete documentation from prior work;
- personal reminders intentionally given to Concierge;
- weather relevant to the day;
- other Roundhouse information that materially affects today's plan.

Daily Grind should reference information from Roundhouse systems rather than duplicate those systems. For example, Concierge may point out an incomplete Resolution or missing documentation when it affects today's plan, but Daily Grind does not recreate the Resolution or documentation system.

**Daily Grind → Concierge comes to you.**  
**Hold CAPTURE → you call Concierge.**

## Governing Rules

1. **Concierge is a Command Center function, not a separate screen.**
2. Concierge receives no additional permanent Command Center button; CAPTURE is the entry point.
3. **Tap CAPTURE = capture. Hold CAPTURE = talk to Concierge.**
4. Concierge activation must be deliberate and visibly indicated to prevent accidental activation from becoming disruptive.
5. An animated CAPTURE state indicates an active Concierge working session.
6. Concierge can use photographs and notations created during the active session as working context.
7. Concierge should help convert useful answers into durable Roundhouse actions, lists, documentation, reminders, or Records where appropriate.
8. Concierge may travel through Command Center work tools and appropriate deeper work destinations while already active.
9. Concierge does not follow the person into Mail / Messages or Reward Center.
10. Daily Grind is the Concierge's proactive morning appearance, not the Concierge's permanent home.
11. Concierge is focused on Roundhouse work, practical planning, research, documentation, purchasing needs, and related assistance—not unrestricted general conversation.
